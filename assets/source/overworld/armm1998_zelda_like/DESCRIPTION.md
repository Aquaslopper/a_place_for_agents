# Zelda-like tilesets and sprites — accompanying description

Source page: https://opengameart.org/content/zelda-like-tilesets-and-sprites
Author: ArMM1998. License: CC0 1.0 (public domain). Posted 2017-02-16.

## Publisher description
A complete Zelda: A Link to the Past-flavoured 16x16 top-down pixel-art kit:
overworld terrain, objects, characters, NPCs, cave interiors, a font and UI.
The source page notes it includes "a font in there, some great UI stuff, a
paper backdrop, a LIVING LOG CHARACTER" and animated water.

## Sheets (the `gfx.zip` download, unchanged)
- Overworld.png (640x576) — overworld terrain + buildings + props. 40 tiles/row.
- objects.png  (528x320) — trees, rocks, fences, signs, furniture, props.
- character.png (272x256) — the player / hero walk sheets.
- NPC_test.png (64x128)  — NPC sprites.
- cave.png (—)           — cave / interior tiles.
- Inner.png (—)          — interior tiles.
- font.png (—)           — bitmap font.
- log.png (—)            — the "living log" character / paper backdrop.
